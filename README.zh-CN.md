# 远程桌面 · iPad / Android

[English](README.md) | 中文

在外面使用 **Android 手机 / 平板、iPad 原生 App 或 Safari 网页**，即可远程查看并操控家里的 **Windows / Mac**，支持触摸、鼠标、实体键盘及常用快捷键。Android 与 iPad 原生客户端都不是网页套壳；被控电脑继续使用已有 Windows/Mac 服务端。

- **主通道：Tailscale**。点对点直连，地址固定，全程 WireGuard 加密。电脑和 iPad 登录同一个 Tailscale 账号即可，不需要公网 IP，也不用设置路由器端口转发。
- **备用通道：Cloudflare 临时隧道**。不需要账号，iPad 不装任何 App，任何网络都能用 https 打开。缺点是电脑每次重启后地址会变，新地址会自动推送到你专属的 ntfy 频道。
- **隐私屏**：远程控制时，电脑本地屏幕显示锁屏画面，家里的人看不到你在做什么；你在 iPad 上看到的仍然是真实桌面。

## 一、安装（电脑上，只需一次）

### Windows

1. 到 [Releases 页面](https://github.com/haoawake/ipad-remote-desktop/releases/latest) 下载 **`iPad-Remote-Desktop-win-x64.zip`**，解压到一个固定的位置（比如 `D:\iPad远程桌面`）。这是免安装版，已经自带 Python 和所有依赖，**不用另外装 Python**。
2. 安装 [Tailscale](https://tailscale.com/download) 并登录。iPad 也装 Tailscale App，登录**同一个账号**。
3. 双击 **`启动远程桌面.bat`**。如果 Windows 提示“无法验证发布者”，点「运行」。第一次运行会：
   - 生成随机密码和配置文件 `config.json`；
   - 自动下载 `cloudflared.exe`（约 50MB，来自 Cloudflare 官方 GitHub Release）；
   - 在窗口里显示登录密码、Tailscale 地址、备用地址和 ntfy 频道（同时写入 `访问地址.txt`）。
4. （可选）双击 **`开机自启-开启.bat`**，以后登录 Windows 后会自动在后台启动。

> **从源码运行**：先安装 [Python 3.10+](https://www.python.org/downloads/)（安装时勾选 “Add python.exe to PATH”），双击 **`安装依赖.bat`**（等价于 `pip install -r requirements.txt`），其余步骤一样。启动脚本发现旁边有 `runtime\python.exe`（免安装版自带的）就用它，否则用系统里的 Python。

> 不需要管理员权限。Tailscale 通道用 `tailscale serve` 把 tailnet 的 80 端口转到本机，不用改防火墙。

### Mac

1. 下载 **`iPad-Remote-Desktop-mac-arm64.zip`**，双击解压，把 **「iPad 远程桌面」** 拖进 **「应用程序」** 文件夹。里面已经自带运行环境，不用装 Python。
2. **第一次打开**：在「应用程序」里双击它。因为没有花钱买苹果的开发者签名，macOS 会提示“Apple 无法验证……”，点「完成」。然后打开 **系统设置 → 隐私与安全性**，往下翻到“已阻止打开「iPad 远程桌面」”，点 **「仍要打开」**，输入 Mac 的登录密码确认。以后就能直接双击了。（macOS 12 及更早：在「应用程序」里按住 Control 点它 → 打开 → 打开；或者到「系统偏好设置 → 安全性与隐私 → 通用」点「仍要打开」。）
   （会用终端的话，也可以执行 `xattr -cr "/Applications/iPad 远程桌面.app"` 后再双击。）
3. **打开两项系统权限**：程序窗口顶部会提示“还差 2 项系统权限”，点旁边的按钮进入对应的设置页，在列表里找到「iPad 远程桌面」，打开开关：
   - **屏幕录制**（新版系统里叫“录屏与系统录音”）：没有它，iPad 上只能看到桌面背景。打开后如果系统提示「退出并重新打开」，点它。之后系统还会问一次“「iPad 远程桌面」正在请求绕过系统专用窗口选择器……”，点 **「允许」**。
   - **辅助功能**：没有它，iPad 上点不动、打不了字，隐私屏也拦不住本机键盘鼠标。
4. 安装 [Tailscale](https://tailscale.com/download/mac)（Mac App Store 里也有）并登录。iPad 也装 Tailscale App，登录**同一个账号**。
5. 程序窗口里会显示**登录密码、Tailscale 地址、备用地址和 ntfy 频道**，每一项旁边都有「拷贝」按钮。第一次运行会自动下载 cloudflared（约 20MB，来自 Cloudflare 官方 GitHub Release）。
6. （可选）勾选窗口下方的 **「登录 Mac 后自动启动」**。

> 关掉这个窗口**不会**停止服务（点程序坞里的图标可以再打开）；要停止，点「停止并退出」或按 ⌘Q。程序崩溃会自动重启。

> 第一次打开时如果系统问“是否允许访问‘下载’文件夹”，点「允许」——iPad 传来的文件保存在那里。

## 二、出门前在 iPad 上做一次（5 分钟）

1. 打开 Tailscale App，确认已连接。
2. Safari 打开程序窗口里显示的 Tailscale 地址（形如 `http://100.x.y.z`，或 `http://电脑名.你的tailnet.ts.net`），输入密码，勾选“记住 30 天”。
3. 点 Safari 的 **分享 → 添加到主屏幕**。以后从这个图标打开就是全屏，跟 App 一样。
   - 主屏幕图标和 Safari 的登录状态是分开的，第一次从图标打开要再输一次密码。
4. （建议）订阅备用地址推送：在 App Store 装 **ntfy**，添加订阅，频道名填 `访问地址.txt`（Mac 上在程序窗口里）里 `ntfy.sh/` 后面那串（形如 `rd-xxxxxxxx`）。不想装 App 的话，就把 `https://ntfy.sh/rd-xxxxxxxx` 加个 Safari 书签。

## 三、在外面使用

1. iPad 打开 Tailscale 并连接，然后点主屏幕上的“远程桌面”图标。
2. 如果 Tailscale 连不上（比如 iPad 正在用别的 VPN，iOS 同一时间只能开一个 VPN），就打开 ntfy 推送或书签，点里面的 `https://xxxx.trycloudflare.com` 地址，用同一个密码登录。

## 四、操作方式

顶部工具栏：**键盘 · 快捷键 · 模式切换 · 隐私屏 · 网址 · 剪贴板 · 传文件 · 设置 · 全屏**。最右边的 ^ 可以收起工具栏；收起后点顶部的小箭头，或者**双指按住屏幕 1 秒**就能重新打开（全屏时也能用）。

| 手势 | 触控板模式（默认） | 直接点击模式 |
|---|---|---|
| 单指滑动 | 移动鼠标 | 按住左键拖拽 |
| 轻点 | 左键单击（连点两下＝双击） | 在手指位置单击 |
| 长按 | 按住左键开始拖拽 | 右键 |
| 轻点后立刻按住滑动 | 拖拽（选文字、拖窗口） | — |
| 双指轻点 | 右键 | 右键 |
| 双指上下/左右滑 | 滚轮（带惯性） | 滚轮（带惯性） |
| 双指捏合 | 放大画面（放大后鼠标走到边缘会自动跟随） | 放大并移动画面 |
| 双指按住 1 秒 | 打开 / 收起工具栏 | 打开 / 收起工具栏 |

中键、双击，以及“下一次点击按住 Ctrl/Shift”（比如多选文件）都在快捷键面板里。Apple Pencil 不管在哪个模式下都按“直接点击”处理。

- **外接实体键盘（v1.1.1 起）**：连接成功后直接按键即可操作远程电脑；如果此前点过网页上的按钮，轻点一次远程桌面让键盘焦点回到画面，无须点击顶部“键盘”。英文、数字、方向键、回车、退格及多数快捷键会转发到电脑。Windows 被控端默认将 iPad 的 ⌘ 映射为 Ctrl，Mac 被控端保持 ⌘（可在设置中切换）。
- **iPad 屏幕键盘与中文输入法**：仍可点顶部“键盘”唤出屏幕键盘并输入中文；长段文字可通过“剪贴板”直接输入。
- **iPadOS 限制**：部分系统级快捷键（如 ⌘Tab 切应用、⌘空格切输入法）会先被 iPadOS/Safari 接管，网页无法保证拦截。需要对远程电脑执行这些组合键时，用顶部“快捷键”面板；特别是 Windows 的 Ctrl+Alt+Del 安全桌面操作无法通过普通远程键盘注入。
- **快捷键面板**：复制、粘贴、撤销、Alt+Tab、显示桌面、任务管理器、方向键、F1–F12、音量等。Ctrl/Shift/Alt/Win 点一下会对下一个按键或点击生效，双击就一直锁定（变橙色）。
- **电脑是 Mac 时**，快捷键面板自动换成 Mac 的一套：⌘ ⇧ ⌥ ⌃ 四个修饰键，复制 ⌘C、重做 ⇧⌘Z、刷新 ⌘R、切换应用 ⌘Tab、调度中心、显示桌面、聚焦搜索 ⌘空格、切换输入法、全屏、退出应用 ⌘Q、强制退出 ⌥⌘Esc、活动监视器、访达、截图 ⇧⌘4、音量等。
- **打开网址**：点“网址”输入地址（如 `bilibili.com`），电脑会用默认浏览器打开，最近用过的会记下来。
- **传文件**：照片和文件会保存到电脑的 `下载\iPad传来的文件`（Mac 上是「下载」里的「iPad传来的文件」）。
- **外接妙控键盘、鼠标、触控板**都可以直接用。电脑是 Windows 时 ⌘ 默认当作 Ctrl（⌘C＝复制）；电脑是 Mac 时 ⌘ 就是 Mac 的 ⌘。都可以在设置里改。
- **画质**：设置里选“省流量 / 均衡 / 清晰”。用流量建议选均衡：画面不动时几乎不耗流量，大面积变化时一帧约 100–200KB。画面静止约半秒后，程序会自动把这块区域用高画质补发一遍，所以文字会变清楚。Mac 的 Retina 屏像素多，用流量时可以选“省流量”（正好是屏幕的原始“点”分辨率，文字依然清楚）。

## 五、隐私屏（远程时电脑上显示锁屏画面）

iPad 一连上，电脑屏幕就会盖上一层锁屏画面（时钟 + “此电脑正在被远程使用”），家里的人看不到你在做什么，电脑本机的键盘和鼠标也会暂停。你在 iPad 上看到和操作的仍然是真实桌面。

- 工具栏的 **隐私屏** 按钮可以随时开关。iPad 会记住你的选择，下次连接自动按这个设置。
- 你断开以后锁屏画面**不会自动消失**，防止你最后停留的页面露出来。
- **在电脑前怎么解除**：等远程断开 2 分钟后，在电脑上按 **Enter** → 进入 Windows 锁屏 → 用开机密码 / PIN 解锁，锁屏画面自动消失（只有知道 Windows 密码的人能解除）。Ctrl+Alt+Del 随时可用，选“锁定”再解锁也一样。
- **Windows 的限制**：开始菜单、Alt+Tab 切换界面、系统通知会浮在锁屏画面上面。电脑声音照常外放，本地能看到鼠标指针在动（但看不到内容）。尽量用“网址”按钮和任务栏打开程序，少用开始菜单搜索。
- 原理：一个置顶、鼠标穿透、不抢焦点的全屏窗口，设置了 `WDA_EXCLUDEFROMCAPTURE`，只显示在物理屏幕上，截屏里不存在；本机键盘鼠标用低级钩子拦截，只放行程序注入的远程输入。需要 Windows 10 2004 及以上。

### Mac 上的隐私屏

- **在 Mac 前怎么解除**：等远程断开 2 分钟后，在 Mac 上按 **Enter** → Mac 锁屏 → 用登录密码（或触控 ID）解锁，锁屏画面自动消失。只有能解开这台 Mac 的人能解除。
- 锁屏画面盖在菜单栏、程序坞、通知、全屏应用、调度中心**上面**，每块显示器都盖；按 ⌘H、⌥⌘H、显示桌面也藏不掉它。
- **Mac 的限制**：
  - 鼠标指针的移动在 macOS 上拦不住（系统先挪指针、再发事件），程序会马上把指针拉回远程最后放的位置，所以本机动鼠标只会看到指针抖一下，点不了任何东西。
  - 远程那边光标正停在**密码输入框**里时，macOS 会让键盘输入绕过所有拦截程序，这时候本机键盘能打进那个密码框。
  - 电脑声音照常外放；音量、亮度的提示浮窗可能浮在锁屏画面上面。屏幕右上角会露出一个紫色小圆点（macOS 提示“正在录屏”的标记，所有录屏程序都一样，盖不住）。
  - 没有「辅助功能」权限时只能遮住屏幕，拦不住键盘鼠标；这时在 Mac 前按 ⌃⌘Q 锁屏、再用登录密码解锁，也能解除。
- 原理：每块显示器一个“屏蔽层”级别（`CGShieldingWindowLevel`）的全屏窗口，鼠标穿透、不抢焦点；截屏时只截这个窗口**下面**的所有窗口（`CGWindowListCreateImage` 的 OnScreenBelowWindow 模式），所以 iPad 上是真实桌面；本机键盘鼠标用事件拦截（CGEventTap）挡掉，只放行本程序注入、带了标记的事件。

## 六、电脑这边要注意

- 黑色窗口“iPad 远程桌面 - 运行中”**不要关**，可以最小化。关掉就断开了。程序崩溃会自动重启。
- 如果电脑在你不在家时**重启了**（比如自动更新），要有人在电脑上登录 Windows，程序才会启动。建议出门前暂停 Windows 更新。
- **不要锁屏（Win+L）**。锁屏后画面和输入都会被系统隔离，在外面没法解锁。程序运行期间会主动阻止电脑睡眠和关屏。
- 笔记本**不要合盖**（合盖后没有可截的屏幕），可以把屏幕亮度调低。建议把“合上盖子时”设为“不采取任何操作”。
- 弹出“是否允许此应用更改设备”（UAC）这种管理员窗口，或者以管理员身份运行的程序（如任务管理器），远程点不动。这是 Windows 的安全限制。
- 程序运行期间会保持 Tailscale 开启。如果 Tailscale 托盘程序被关了，程序会在 1 分钟内把它重新打开。

### Mac

- 程序窗口可以关（服务照常运行），但**不要退出程序**（⌘Q / 「停止并退出」就是停止）。
- **不要锁屏**（⌃⌘Q、菜单 → 锁定屏幕、按触控 ID 键）。锁屏后在外面没法解锁。程序运行期间会阻止 Mac 睡眠和关屏，「系统设置 → 电池 / 锁定屏幕」里不用改。
- MacBook **不要合盖**：合盖就会睡眠（除非接着电源和外接显示器）。
- Mac 重启后（比如系统更新），要有人在 Mac 上登录，程序才会启动（开了“登录后自动启动”的话会自动启动）。开了 FileVault 的 Mac 重启后必须在电脑前输一次密码。建议出门前把「系统设置 → 通用 → 软件更新 → 自动更新」里的“安装 macOS 更新”关掉。
- 系统的密码弹窗（比如安装软件、改系统设置时要输入管理员密码）远程打不进字，这是 macOS 的安全限制。
- 程序运行期间会保持 Tailscale 开启：菜单栏里的 Tailscale 被退出了，程序会在 1 分钟内把它重新打开。

## 七、文件和配置

| 文件 | 作用 |
|---|---|
| `启动远程桌面.bat` | 启动服务（崩溃会自动重启） |
| `停止远程桌面.bat` | 停止服务 |
| `开机自启-开启.bat` / `开机自启-关闭.bat` | 开启或关闭开机自启 |
| `重置密码.bat` | 换一个新密码，所有设备需要重新登录 |
| `安装依赖.bat` | 安装 Python 依赖（只有从源码运行才需要） |
| `runtime\` | 免安装版自带的 Python 运行环境 |
| `访问地址.txt` | 当前密码和地址（运行后自动生成） |
| `config.json` | 配置（第一次运行自动生成） |
| `data\run.log` | 运行日志（登录记录、错误） |
| `app\` | Python 服务端：截屏编码、输入注入、穿透、隐私屏 |
| `web\` | iPad 网页端 |

Mac 上这些 .bat 的功能都在程序窗口里（重置密码、登录后自动启动、停止并退出），配置和日志放在 `~/Library/Application Support/iPad 远程桌面/`（窗口里点「打开数据文件夹」）：`config.json`、`访问地址.txt`、`data/run.log`（服务日志）、`data/app.log`（窗口程序日志）、`bin/cloudflared`。“登录后自动启动”是 `~/Library/LaunchAgents/com.haoawake.ipad-remote-desktop.plist`。

`config.json` 里可以改的项：

| 键 | 默认 | 说明 |
|---|---|---|
| `password` | 随机生成 | 登录密码 |
| `port` | `8765` | 本机服务端口（只监听 127.0.0.1） |
| `tailscale` | `true` | 是否自动配置 Tailscale 通道 |
| `cloudflare` | `true` | 是否开启 Cloudflare 备用通道。只用 Tailscale 就改成 `false`，电脑完全不暴露在公网上 |
| `ntfy_topic` | 随机生成 | 备用地址推送频道，留空则不推送 |
| `keep_display_on` | `true` | 运行期间阻止关屏 |
| `privacy` | `true` | 是否启用隐私屏功能 |
| `privacy_block_input` | `true` | 隐私屏开启时是否屏蔽本机键盘鼠标 |
| `upload_dir` | `%USERPROFILE%\Downloads\iPad传来的文件`（Mac：`~/Downloads/iPad传来的文件`） | 上传文件保存位置 |

改完要重启程序。

> **Mac 从源码运行**：`python3 -m pip install -r requirements-mac.txt`，然后 `python3 app/mac_main.py`。注意这样运行时，权限要授给“终端”（或你用的那个程序），而不是「iPad 远程桌面」。自己打包：`python3 -m pip install pyinstaller && python3 scripts/build_mac.py 1.1.0`（Intel 的 Mac 也可以这样自己打一个）。

## 八、安全设计

- 必须输入密码才能看到画面。登录有防暴力破解：同一地址 10 分钟内错 5 次就锁定，全局错 20 次锁定 10 分钟。
- 登录凭证是 HttpOnly Cookie，WebSocket 会校验来源，防止被别的网站盗用。
- 服务只监听本机 `127.0.0.1`，局域网里的其他设备连不上。外部只能经过 Tailscale（WireGuard 加密）或 Cloudflare（https）进来。
- “打开网址”只允许 http/https。
- Mac 版第一次运行下载的 cloudflared 钉死了版本并校验 SHA256。

## 九、常见问题

- **页面一直显示“正在重连”**：先确认 iPad 的 Tailscale 是连上的；还不行就用 ntfy 里的备用地址。如果两个都不行，大概率是电脑关机、睡眠或断网了。
- **画面卡**：设置里切换到“省流量”，或者把帧率调到 15。打开“显示延迟 / 帧率 / 流量”可以看到实时数据。
- **按键像是卡住了**（比如一直按着 Ctrl）：设置 → 松开所有按键。
- **画面花了或缺块**：设置 → 刷新画面。
- **找不到工具栏**：双指按住屏幕 1 秒。

### Mac 常见问题

- **双击打不开，提示“Apple 无法验证”或“已损坏”**：见上面安装第 2 步（系统设置 → 隐私与安全性 → 仍要打开）。还不行就在终端执行 `xattr -cr "/Applications/iPad 远程桌面.app"`。
- **iPad 上只看到桌面背景、看不到任何窗口**：没开「屏幕录制」权限。打开后退出程序（⌘Q）再重新打开。
- **iPad 上点了没反应、打不了字**：没开「辅助功能」权限。
- **更新到新版本后权限好像失效了**：免费签名的程序，系统是按程序内容认的，换了版本就当成新程序。在「系统设置 → 隐私与安全性 → 屏幕录制 / 辅助功能」里选中旧的「iPad 远程桌面」，点「−」删掉，再打开程序重新授权。
- **macOS 隔一段时间又问一次“是否允许……绕过系统专用窗口选择器 / 继续录屏”**：这是 macOS 15 起对所有录屏程序的规定（大约每月一次），点「允许」即可。弹窗开着的时候 iPad 上照常有画面、也看得到这个弹窗，可以直接在 iPad 上点「允许」试试；点不动的话，回到电脑前再点。
- **Mac 上的输入法被换成了英文（ABC）**：Mac 当前是拼音之类的输入法时，从 iPad 打的字会先进 Mac 输入法的候选框，所以远程打字时程序会把 Mac 临时切到英文键盘（中文照样能打，用的是 iPad 自己的输入法）；远程断开 2 分钟后会切回原来的输入法。
- **Intel 芯片的 Mac**：没有现成的安装包，可以按上面“Mac 从源码运行”自己打包。
